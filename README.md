# noesunsimuladordea
LA siguiente aplicación WEb fue desarrollada entre un equipo de Tecnicos y Simulacionistas Argentinos y Pampeanos, buscando romper con una estructura cerrada,  
 desarrollando artefactos que cunmplan con la función de simular un Desfribrilador Automatico/Semiautomatico Externo con Hardware/Software libre, donde planteamos
 las 4 liberetades, usarlo libremente para cualquier cosa (Libertad 0), estudiarlo y modificarlo libremente (Libertad 1), Reproducirlo libremente (Libertad 2) y
 mejorarlo libremente y compartir dichas modificaciones (Libertad 3) 

Desarrolador: Gonzalo Gaspar Gaita TSF - CODES - CeSIM - La Pampa - Argentina - 2026

Una interfaz sencilla para simuladores DEA / DESA totalmente interactivos
